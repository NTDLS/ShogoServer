# ShogoServer
Augmented version of the original ShogoServer from 1998.

This server is built on Windows 2000 using Visual Studio 6.0 with Service Pack 6, although it would probably build fine on Windows 2003, 2008/r2, XP and 7.

The purpose of the augmentation was to allow the server to register with ShogoServers.com as well as respond to health checks.
